# Heart Disease Prediction

## 1. Overview
This project aims to develop a machine learning model to predict the likelihood of heart disease based on patient health data. Various classification algorithms, including Logistic Regression, Decision Tree, Random Forest, and Naïve Bayes, were implemented and evaluated to determine the best-performing model.

## 2. Features
- Data preprocessing and feature scaling
- Implementation of multiple ML models
- Model evaluation using accuracy, precision, recall, and confusion matrix
- Visualization of key insights using Matplotlib and Seaborn

## 3. Tech Stack
- Python
- Pandas & NumPy
- Scikit-Learn
- Matplotlib & Seaborn

## 4. Results & Findings
- The best model achieved an accuracy of **92%**.
- Feature importance analysis identified key health indicators affecting heart disease risk.

## 5. Future Enhancements
- Integration with a web application for real-time predictions
- Exploring deep learning models for improved accuracy
